### 알고리즘: 그리디 알고리즘, dp
### 자료구조: -
### 사고과정 
1. 입력 받은 정수에 대해서 어떤 경우가 되는지를 정리하면 되는 문제이다. 경우는 총 4가지로 나뉜다.
   - 5의 배수인 경우
   - 5의 배수와 3의 배수의 합인 경우
   - 오직 3의 배수인 경우
   - 그 외
2. 각각의 경우에 맞게 조건문을 사용하여 구현하면 된다.

### 성찰
1. 그리디와 dp의 경우는 초기 문제를 풀 때 각각의 경우의 수를 파악하는 것이 중요하다. 먼저 바로 알고리즘을 짜면 실수가 많으니 꼭 많은 예시를 들어 적용하여 확실한 경우의 수를 파악하는 것이 중요하다.
### 다른 풀이 
동일하게 조건문을 활용했지만 내 풀이 보다 훨씬 깔끔한 코드여서 참고하러 가져왔다. 
  ```python
num = int(input())
count = 0

while num >= 0:
  if num % 5 == 0:
    count += int(num // 5)
    print(count)
    break
  
  num -= 3
  count += 1
  
else:
  print(-1)

```
