### 알고리즘: dp
### 자료구조: -
### 사고과정 
1. 피보나치 문제는 대표적인 dp 문제이다. 하위 문제를 먼저 풀고 답을 얻은 후 상위 문제를 해결할 때 하위 문제로 나누어 값을 구하는 것이다.
그러면 당연하게 0과 1의 값이 호출되는 개수 또한 dp 문제라고 볼 수 있다.
2. 재귀를 이용하여 dp를 푼다면 테스트 케이스 마다 N 복잡도를 가지게 되므로 O(T * N)를 가지게 된다. 메모제이션을 사용해서 전 테스트 케이스에서 저장한 값을 활용한다면 O(N + T)를 가질 수 있다.
3.   - 혹은 먼저 0부터 40까지 값을 미리 구해놓아도 된다.
4. 기존 0, 1일때 피보나치 값을 구할 때 필요한 0, 1의 개수를 각각 다른 배열에 저장해놓고 메모제이션 기법을 사용하여 구하면 된다. 
### <성찰>
코딩테스트는 다다익선이 맞는거 같다. 물론 그 문제에 대한 깊은 이해도 필요하지만 최대한 많은 유형을 풀어서 익히는게 중요하다.
