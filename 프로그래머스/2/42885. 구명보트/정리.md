# 🛶 오답노트

### 💡**문제 분석 요약**

사람들을 보트에 태워 구출해야하는데 최대 2명씩 탈 수 있고 무게제한이 있다. 이때 사람들을 모두 구출할 수 있는 구명.보트 최솟값을 구하시오.

제한사항

- 무인도에 갇힌 사람은 1명 이상 50,000명 이하입니다.
- 각 사람의 몸무게는 40kg 이상 240kg 이하입니다.
- 구명보트의 무게 제한은 40kg 이상 240kg 이하입니다.
- 구명보트의 무게 제한은 항상 사람들의 몸무게 중 최댓값보다 크게 주어지므로 사람들을 구출할 수 없는 경우는 없습니다.

### 💡**알고리즘 설계**

투-포인터 알고리즘 적용한다.  (하단 블로그 참조)

[알고리즘) Two-Pointers Algorithm (투 포인터)](https://velog.io/@wltjd3459/알고리즘-Two-Pointers-Algorithm-투-포인터)

리스트를 오름차순으로 정렬한다. 그리디 알고리즘은 어떤 것이 제일 효율적인지 판단해서 최적의 선택을 실행하는 방법이다. 따라서 지금의 최적은 제일 가벼운 사람과 제일 무거운 사람의 합이 limit을 넘는지 확인하는 방법일 것이다. 

따라서 투- 포인터 알고리즘을 적용해서 문제를 풀어야 한다. 

1. start = 0, end = len(list) -1
2. 합이 limit가 넘으면 end -=1 실행하고 answer++
3. 합이 limit가 안넘으면 start ++, end —, answer ++ 
4. 이걸 start == end 이면 answer ++
5. start보다 end가 크면 break
