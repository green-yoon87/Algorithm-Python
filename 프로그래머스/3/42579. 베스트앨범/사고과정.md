### 알고리즘: 구현
### 자료구조: hash -value
### 사고과정 
장르로 나눠 제일 많이 재생된 장르를 기준으로 정렬해야한다. 따라서 딕셔너리를 이용하여 각 장르마다 재생된 수를 합하여 정렬한다.  -> generDict 사용
각 장르를 key로 하고 장르에 포함되는 노래 리스트를 value 설정한다. 이때 노래 리스트에 원소를 추가할 때 (재생된 수, index)로 추가한다. 
나머지 구현
높은 재생 수를 가진 장르에 포함되는 노래들을 출력한다. -> 이때 리스트를 재생수를 기준으로 일차 내림차순 정렬하고 index에 대해서 2차적으로 오름차순 정렬하여 출력한다. 

### <성찰>
이제 hash - value를 이용하는 구현 문제의 난이도는 비교적 쉽게 느껴진다. 다만 파이썬에 대한 언어 숙련도 및 문제에 대해서 꼼꼼히 조건을 체크할 필요는 있다.
