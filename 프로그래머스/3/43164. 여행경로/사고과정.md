### 알고리즘: 구현, bfs or dfs 
### 자료구조: -
### 사고과정 
모든 티켓을 사용해야하고, 모든 도시를 방문해야하는 경로를 구해야한다. 만일 가능한 경로가 2개 이상일 경우 알파벳 순서가 앞서는 경로를 return해야한다. 
경로에 대해서 위 조건을 만족하는 도시를 찾아야 하므로 dfs 방식을 사용했다. 먼저 각 도시 출발 티켓이 있는 경우 그 도시에 출발 도시들을 저장하였다.  이때 key(도시 이름) - value(도착 도시들)로 dictionary를 사용하였다.
티켓들에 대해서 각각 몇장 가지고 있는지를 저장하였다. (이 또한 key-value를 사용하였다.) - 처음에는 true/false로 했으나 동일한 티켓이 여러개 있는 경우가 있어서 개수를 저장하였다.
dfs를 적용해보자. 여기서 노드와 간선은 무엇인가. 여기서 노드는 나라이고 간선은 티켓이라고 할 수 있다. 하지만 중요한 것은 여러 동일한 티켓이 있으면 동일한 간선이라고 취급하면 안된다는 것이다. 다르게 취급하고 그 간선을 모두 사용해야 한다!
dfs 경로를 저장하는 리스트와 정답을 담는 리스트를 전역적으로 정의한다. 그리고 경로 리스트의 길이가 티켓 수 + 1일 시에 정답 리스트에 저장한다. (이때 정답리스트가 비워있는 경우에만 저장한다. -> 알파벳 순으로) 
### <성찰>
문제에 맞게 dfs를 구현하는데 오래 걸렸다. 또한 edge case에 대해서 혼자 힘으로 떠올리지 못했다. 정형화된 dfs나 bfs에 벗어나지 않는 것이 큰 패착이다. 문제에 맞게 확장 및 변형할 필요가 있고 이는 문제 정의하는 것을 더욱 체계화하여 해결할 수 있다. 따라서 이처럼 많은 조건이 있는 문제들은 수기로 작성하여 필요 조건을 가시화할 필요가 있ㅏ.
앞으로 문제가 정확히 어떤것인지 어떤 문제가 발생할 수 있는지 수도 코드를 수기로 작성하는 것이 도움이 될 거 같다.

### <다른 풀이>
개인적으로 정말 깔끔하고 잘 작성된 코드라고 생각해서 가져왔다. 
bfs를 사용한 문제 풀이이다. 첫 시작인 ICN에서 각 ticket의 사용여부를 빈 리스트에 담당하여 해당 인덱스가 포함되어 있는지 확인한다. 별도의 key-value를 사용하지 않고 리스트를 순회하면서 모든 path를 찾고 해당 path를 answer에 추가하고 sort()하여 답을 구한다. 
```python
from collections import deque
def solution(tickets):
    answer = []
    q = deque()
    q.append(("ICN",["ICN"], []))

    while q:
        airport, path, used = q.popleft()
        print(airport, path, used, answer)

        if len(used) == len(tickets):
            answer.append(path)

        for idx, ticket in enumerate(tickets):
            if ticket[0] == airport and not idx in used:
                q.append((ticket[1], path+[ticket[1]], used+[idx]))


    answer.sort()

    return answer[0] 
```
